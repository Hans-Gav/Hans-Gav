About

What started as IT support has grown into full infrastructure engineering — server administration, container orchestration, and network architecture for a company that can't afford downtime, since it runs a pharmacy platform people depend on.

Day to day that means Linux and Windows server administration, Docker and Docker Compose deployments, CI/CD pipelines with GitHub Actions, MikroTik network configuration, and Cloudflare's edge stack — DNS, Tunnels, and Zero Trust — plus supporting the internal applications built on top of it all.
